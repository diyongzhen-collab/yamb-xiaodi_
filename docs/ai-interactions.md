# 新增 AI 交互工具

当前注册表共 27 个工具。本次新增以下五个工具，白名单用户及管理员可用。

| 工具 | 功能 | 参数 | 锁定时 |
| --- | --- | --- | --- |
| `morph_player` | 请求伪装为玩家 | 可选 `player`，省略为发起者 | 禁止 |
| `mount_player` | 骑乘玩家 | 可选 `player`，省略为发起者 | 禁止 |
| `board_minecart` | 登上附近矿车 | 无 | 禁止 |
| `go_home` | 发送 `/home` | 无 | 禁止 |
| `sign_in` | 发送 `/tsl signin click` | 无 | 允许 |

用法：私聊 `ai 伪装成 Steve`、`ai 骑在我身上`、`ai 上附近的矿车`、`ai 回家`、`ai 签到`。直接发送已有文字命令或固定短语仍由原有命令入口处理。

伪装与文字 morph 命令共用请求流程：发送申请，等待同意或已解锁响应，提交变身后十分钟恢复原配置形态。请求成功不代表变身已完成；超时、发送失败和断线沿用原清理与通知机制。AI 传入的玩家名必须为 1–16 位字母、数字或下划线；匹配歧义会返回失败，不能任意选取。

骑乘和上矿车与文字命令共用操作及骑乘状态管理。下马未成功时，不继续切换玩家目标；上矿车或骑乘失败不会被工具报告成成功。

回家与签到仅报告固定服务器指令是否提交，不能保证服务端已经传送或签到成功。AI 的斜杠指令黑名单仍适用于 `/home`、`/tsl`、伪装的 `/request` 与 `/morph`。

验证：43 项本地测试通过，TypeScript 编译通过；未连接真实服务器或付费 AI 验证。现已纳入 3.1 发布内容。
